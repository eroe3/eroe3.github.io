Ethereal Raven Field Manual: a practical introduction to preparing for a safe day outdoors.

Field Manual

Plan the Route Pack the Essentials Read the Terrain Communicate Clearly Leave No Trace

Plan the Route

Begin with a route that matches the group, daylight, and forecast. Mark a turnaround time before leaving.

Write the basic plan in a compact format:

START → CHECKPOINT → TURNAROUND → RETURN
  • Share the route with someone who is not on the trip.
  • Carry an offline map and a physical backup.

Pack the Essentials

Build the pack around water, weather protection, navigation, first aid, light, and communication.

Use a short pre-departure check:

WATER + LAYERS + MAP + LIGHT + FIRST AID
  • Fit the load before the trip.
  • Keep urgent equipment accessible.

Read the Terrain

Compare the map to visible ridges, trails, streams, structures, and changes in elevation.

Stop when the surroundings no longer match the plan:

STOP → OBSERVE → ORIENT → PLAN
  • Confirm direction before increasing distance.
  • Notice conditions that could change the return route.

Communicate Clearly

Good field communication is brief, calm, and specific. State who you are, where you are, and what is needed.

A useful report follows one consistent order:

NAME → LOCATION → CONDITION → REQUEST
  • Repeat critical details.
  • Set a regroup point before separating.

Leave No Trace

Use durable surfaces, respect closures, secure waste, and leave natural or historic objects in place.

The final check should be simple:

PACK IN → PACK OUT → CHECK AGAIN
  • Minimize noise around wildlife and other visitors.
  • Leave the route ready for the next group.
